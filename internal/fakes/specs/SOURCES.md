# Official API specifications

Vendored, unmodified, used by the fakes in `internal/fakes` to validate every
request and response (see `internal/fakes/contract`).

| File | Source | Format | Version | Fetched |
|---|---|---|---|---|
| `kosli-openapi.json` | https://app.kosli.com/api/v2/openapi.json (served by Kosli) | OpenAPI 3.1.0 | Kosli API 2.0 | 2026-11-23 |
| `octopus-swagger.json` | https://samples.octopus.app/api/swagger.json (generated by Octopus Server) | Swagger 2.0 | Octopus Server 2026.4.13204 | 2026-11-23 |

To refresh: re-download, then run `go test ./internal/fakes/... ./internal/driver/octopus/`.
A changed spec that breaks the fakes or the drivers shows up as contract violations.

Known quirks of the vendor specs (not ours, tolerated by the guard):
- Kosli: some operations reference an undeclared `HTTPBasic` security scheme.
- Octopus: duplicate path templates (e.g. `/accounts/{id}` vs `/accounts/{accountId}`).
